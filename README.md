# ServiceConnect - Local Service Booking App

Flutter + FastAPI app similar to Urban Company for booking Plumbing, Electrical, Cleaning services.

## Features for AGREMATE role
- Flutter / Dart - Premium UI with provider detail, maps card, bottom price bar
- REST API integration - FastAPI backend /providers, /book
- State Management - Provider (migrating to Riverpod)
- Firebase Ready - Auth & Firestore structure ready
- Google Maps SDK Ready - Location card showing distance (real map integration next)
- Multi-user flow inspired by Tenant/Landlord/Guard architecture
